# WesalPulse - Call Center Analytics Platform

## Elevate Your Call Center Performance

WesalPulse is a cutting-edge call center analytics platform that provides real-time insights and comprehensive monitoring capabilities for modern contact centers. Designed for organizations using Genesys Cloud, WesalPulse transforms raw call data into actionable intelligence that drives operational excellence.

## Key Features

### 🚀 Real-Time Monitoring
- **Live Dashboard**: Track active calls, waiting customers, and agent availability
- **Queue Performance**: Monitor wait times, service levels, and abandonment rates
- **Agent Status**: Real-time visibility into agent productivity and availability
- **Instant Alerts**: Critical threshold notifications for immediate action

### 📊 Advanced Analytics
- **Performance Metrics**: Comprehensive KPIs including answer rates, handle times
- **Trend Analysis**: Historical data visualization and pattern recognition
- **Queue Analytics**: Detailed performance breakdown by individual queues
- **Agent Performance**: Individual productivity and efficiency tracking

### 🌐 Genesys Integration
- **Multi-Region Support**: EU (Ireland), EU (Frankfurt), Middle East (UAE)
- **Secure Authentication**: Organization validation and single sign-on
- **Real-Time Sync**: Live data integration with Genesys Cloud platforms
- **Unified Experience**: Seamless workflow between platforms

### 🎨 User Experience
- **Intuitive Interface**: Clean, modern design with drag-and-drop dashboards
- **Customizable Layouts**: Personalized widget arrangements and views
- **Smart Filtering**: Dynamic filtering by media type, queue, and time
- **Interactive Charts**: Rich visualizations for easy data interpretation

## Technology Stack

- **Frontend**: Next.js 15, React 19, TypeScript 5, Tailwind CSS 4
- **Backend**: MongoDB, Socket.IO, NextAuth.js
- **UI Components**: shadcn/ui with Lucide icons
- **Charts**: Recharts for data visualization
- **Real-Time**: WebSocket support for live updates
