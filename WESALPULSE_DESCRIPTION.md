# WesalPulse - Advanced Call Center Analytics Platform

## Overview

WesalPulse is a sophisticated, real-time call center analytics and monitoring platform designed to transform how organizations manage their customer service operations. Built with modern web technologies and integrated with Genesys Cloud, WesalPulse provides comprehensive insights into call center performance, agent productivity, and customer experience metrics.

## Core Purpose

WesalPulse empowers call center managers, supervisors, and executives with actionable data to optimize operations, improve service quality, and enhance customer satisfaction. The platform transforms raw call data into meaningful insights through intuitive dashboards, real-time monitoring, and advanced analytics.

## Key Features

### 🎯 Real-Time Monitoring
- **Live Call Status**: Track active calls, waiting customers, and agent availability in real-time
- **Queue Performance**: Monitor queue metrics including wait times, service levels, and abandonment rates
- **Agent Status**: View agent availability, utilization rates, and current activities
- **Instant Alerts**: Receive notifications for critical performance thresholds

### 📊 Advanced Analytics
- **Performance Metrics**: Comprehensive KPIs including answer rates, handle times, and service levels
- **Trend Analysis**: Historical data visualization to identify patterns and trends
- **Queue Analytics**: Detailed breakdown of performance by individual queues
- **Agent Performance**: Individual agent productivity and efficiency metrics

### 🏗️ Technology Excellence
- **Modern Architecture**: Built with Next.js 15, TypeScript 5, and React 19 for optimal performance
- **Scalable Backend**: MongoDB with Mongoose ODM for flexible data management
- **Real-Time Updates**: Socket.IO integration for live data streaming
- **Responsive Design**: Mobile-friendly interface that works across all devices

### 🔧 Genesys Integration
- **Multi-Region Support**: Seamless integration with Genesys Cloud across EU (Ireland), EU (Frankfurt), and Middle East (UAE)
- **Organization Validation**: Secure authentication with Genesys organization verification
- **Data Synchronization**: Real-time data sync with Genesys Cloud platforms
- **Unified Experience**: Single sign-on and consistent user experience

### 🎨 User Experience
- **Intuitive Interface**: Clean, modern design with shadcn/ui components
- **Customizable Dashboards**: Drag-and-drop widget arrangement for personalized views
- **Smart Filtering**: Dynamic filtering by media type, queue, and time ranges
- **Interactive Visualizations**: Charts and graphs for easy data interpretation

## Technical Specifications

### Frontend Stack
- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript 5
- **UI Library**: React 19 with shadcn/ui components
- **Styling**: Tailwind CSS 4
- **State Management**: Zustand + TanStack Query
- **Charts**: Recharts for data visualization

### Backend Stack
- **Database**: MongoDB with Mongoose ODM
- **Real-Time**: Socket.IO for live updates
- **Authentication**: NextAuth.js v4
- **API**: RESTful endpoints with WebSocket support
- **File Handling**: Sharp for image processing

### Integration Capabilities
